# Shisui

Shisuiは、DNSの切り替え、通信状態の診断、Windowsのネットワーク設定の調整を、ひとつの画面から行えるデスクトップアプリです。

設定に詳しくない場合は「おまかせ高速化設定」、自分で確認しながら使いたい場合は各機能を個別に実行できます。

> **ご注意**
> Shisuiは、ネットワークアダプターやWindowsの通信設定を変更します。実行中に一時的に通信が切れることがあります。
> 起動時に管理者権限を要求します。

## ダウンロード

[Shisuiの最新版をダウンロード](https://shisui.kagayoi.com/Shisui-win.msi)

ダウンロードしたMSIを実行してインストールしてください。以後の更新はアプリ内から適用できます。

旧インストーラー版を利用している場合は、起動時の案内に従って最新版へ移行できます。設定とログは引き継がれます。

## 主な機能

DNSの切り替え（DoH／DoT対応）、DNSキャッシュのクリア、Ping・トレースルート、ゲーム向けのNIC・TCP設定、おまかせ高速化設定、上り速度の制限、ネットワークメンテナンス、使い込んだPC向け診断、自動更新などを備えています。一覧は[主な機能](docs/readme/overview.md)を参照してください。

## おすすめの使い方

基本は、起動時の「自動最適化」でネットワークアダプターを選び、「おまかせ高速化設定」を実行してPCを再起動します。DNSだけの変更、通信状態の確認、ゲーム向けの設定、送信中の遅延対策は[おすすめの使い方](docs/readme/workflow.md)にまとめています。

## 使用前に確認してください

ルーティングテーブルのクリアやリセット操作は通信が切れることがあります。実行前に[使用前の注意点](docs/readme/security.md)を確認してください。

## 動作環境

| 項目 | 内容 |
| --- | --- |
| OS | Windows 10 / 11（64ビット） |
| 権限 | 管理者権限が必要 |
| インターネット接続 | インストール、更新に必要 |

## 困ったとき

DNS設定が反映されない、コマンドが失敗する、設定を保存できない、元へ戻したいといった場合は[困ったとき](docs/readme/troubleshooting.md)を参照してください。
