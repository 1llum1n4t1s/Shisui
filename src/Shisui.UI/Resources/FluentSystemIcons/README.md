# サイドメニューのカラーアイコン

Microsoft Fluent UI System Icons の公式カラー版（MIT License）を使用します。
出典: https://github.com/microsoft/fluentui-system-icons
参照コミット: `9eb184e96268d3293462f9d9d19225b4c7b07774`

| メニュー | 公式アイコン（assets 内のフォルダー） |
| --- | --- |
| 自動最適化 | Design Ideas |
| DNS 設定 | Globe |
| ネットワーク診断 | Data Line |
| BBR2 / TCP 調整 | Gauge |
| メンテナンス | Toolbox |
| バージョン | Question Circle |

SVG は各フォルダーの `SVG/ic_fluent_<名前>_24_color.svg` が原本です。
PNG は原本を 80×80 にラスタライズしたもので、画面では 20×20 で表示します。
実行時の SVG ライブラリは不要です。ライセンス全文は `LICENSE.txt` に保持し、
ビルド・配布出力の `Licenses/FluentSystemIcons.txt` にコピーします。
