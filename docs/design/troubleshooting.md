# ネットワーク診断

遅延診断は4/30/100回のICMP計測に対応し、Windowsでは全試行の成功・失敗を記録します。
p95は成功応答のnearest-rank、ジッターは連続成功間のRTT差の絶対値の平均で、失敗をまたぐ差を含めません。
測定はOSの経路を使い、NIC選択には紐付きません。ICMP統計はゲームの実通信や微小なNIC内遅延の保証には使いません。

名前解決の検証は `example.com` の A レコードを DNS のみ・hosts 不使用で問い合わせ、有効な IPv4 応答の有無を確認します。失敗時は問い合わせ（`Query`）と応答検証（`ResponseValidation`）の段階、PowerShell のエラー ID、例外型、メッセージを標準出力へ記録します。診断値の制御文字は空白に置換し、エラー ID・例外型は各160文字、メッセージは512文字で切り詰めて `...` を付け、ログの行構造と出力量を制限します。

おまかせ後は、DNS キャッシュの再構築と実際の名前解決、NRPT・hosts・変更前境界以降の関連イベントを検査します。失敗・確認不能は保持し、境界の消失・入替え・取得不能を新エラー0件とはみなしません。
