# おすすめの使い方

[README](../../README.md)から移した、目的別の使い方です。

## 設定をおまかせしたい場合

1. 起動時に表示される「自動最適化」で、使用中のネットワークアダプターを選びます。
2. 「おまかせ高速化設定」を実行します。
3. PCを再起動します。

Windowsでは、IP スタックのリセット、DHCP・DNS・DoH の設定、TCP・NIC・電源の設定、Winsock などの修復をまとめて行います。処理の内容と注意は[操作の内容](commands.md)、適用される通信と電源の設定は[適用される設定](configuration.md)、NIC 設定の対象は[NIC 設定の対象と注意](gaming-nic-notes.md)を参照してください。

適用結果は実行ログで確認できますが、速度や遅延の改善を保証するものではありません。

## DNSだけ変更したい場合

1. 「DNS 設定」を開きます。
2. 使用中のネットワークアダプターとDNSを選びます。
3. 「適用」を押します。

元に戻す場合は「自動取得 (DHCP) に戻す」を使用してください。

## 通信状態を調べたい場合

「ネットワーク診断」で対象を選び、Pingまたはトレースルートを実行してください。読み方の注意は[計測の注意と確認例](testing.md)を参照してください。

## ゲームの遅延を優先したい場合

1. ゲームで使う有線またはWi-Fiで接続し、「ネットワーク診断」で同じ相手へ100回測定して、損失率・p95・ジッターを記録します。
2. 「自動最適化」で使用する物理NICを選び、「おまかせ高速化設定」でNIC設定と通信設定をまとめて適用します。
3. PCを再起動し、変更前と同じ負荷・同じ相手で複数回測定します。

NIC 設定の対象と注意は[NIC 設定の対象と注意](gaming-nic-notes.md)を参照してください。NIC の変更は保存された値の確認までで、稼働中の反映や性能は確認できません。ルーターや回線の混雑による遅延は、NIC 設定だけでは解消できません。

## 送信中の遅延を抑えたい場合

大きなアップロードの最中にpingやゲームの遅延が増えるときのための、任意の機能です（Windowsのみ）。「上り速度の制限」タブで回線を計測し、PCの送信合計に上限をかけて待ち行列を抑えます。計測から適用、解除の詳細は[上り速度の制限](uplink-limit.md)を参照してください。
