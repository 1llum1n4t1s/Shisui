# 計測の注意と確認例

[おすすめの使い方](workflow.md)から移した、ネットワーク診断の読み方と測定例です。

- 測定は OS の経路選択を使い、アダプター選択とは連動しません。Windows の RTT はミリ秒単位なので、微小な NIC 内の改善は識別できない場合があります。
- p95 は成功応答の 95 パーセンタイル、ジッターは連続した成功応答の RTT 差の絶対値の平均です。
- ICMP の応答制限による損失は、ゲーム通信の損失とは限りません。
- ルーター・回線の混雑による遅延は、NIC 設定だけでは解消できません。測定結果と設定結果はファイルログにも記録します。
- この 1 台（Wi-Fi）での夜間 1 回の確認では、上限 28Mbps の適用で負荷時の遅延の p90 が 161〜169ms から 21〜25ms に下がりました。別の時刻の 1 回では、計測が提案した 35.0Mbps で 160〜163ms から 24〜25ms でした。回線・時間帯・機器によって結果は異なり、改善は保証されません。
