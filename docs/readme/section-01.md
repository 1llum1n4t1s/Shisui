# 送信中の遅延を抑える（上り速度の制限）

[おすすめの使い方](workflow.md)から移した、上り速度の制限の詳細です。Windows のみの任意機能で、「おまかせ高速化設定」とは別です。

- **計測の通信量**: 測定先（`speed.cloudflare.com`）へ最大 2GB・5 分まで送信します（上り 35Mbps の回線の 1 回では約 460MB・3 分）。上りが約 120Mbps を超える回線では、2GB の上限に届いて完了しないことがあります。画面で通信量と時間を確認してから始め、計測中は他の通信を止めてください。
- **適用の判断**: 結果が「変更不要」「制限しても改善しない」なら、適用は勧めません。上限は、結果を表示した後に[この上限を適用]を押したときだけ設定します。
- **対象**: 上限は、この PC から送信する通信すべてが対象です。家庭内 LAN への転送（NAS へのコピーなど）も同じ上限まで遅くなります。LAN だけを除外することはできません。
- **解除と再適用**: PC を再起動すると解除されます。Shisui を起動すると、同じ回線でだけ再適用します。回線が変わると解除し、起動中に元の回線へ戻ると再適用します。Shisui を起動していない間の回線変更は検知できません。
- **他のポリシー**: 他の QoS ポリシーがあるときは、計測も適用もしません。他のポリシーは変更・削除しません。
- **古い計測**: 計測から 30 日を超えると「古い」と表示します。自動では解除しません。
