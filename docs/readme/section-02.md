# ゲーム向け NIC 設定の対象と注意

[おすすめの使い方](workflow.md)から移した、NIC 設定の対象と注意です。

- NIC をその場で再起動しないため、適用直後に確認できるのはドライバー設定として保存された値までです。稼働中の反映や性能の確認ではありません。
- NIC の変更前の値と Wi-Fi 電源設定の元の値は、アプリの設定ファイルへ保存されます。Wi-Fi 電源設定はメンテナンスから復元できます。
- Wi-Fi は、標準の割り込み調整・RSS・対応オフロードと、対応する MediaTek 製 PCI 無線 NIC の省電力設定が対象です。
- MediaTek RZ616 では、ドライバーが対応値を公開する A-MSDU 送信（`AMSDUTx`）だけを OFF にします。送信側の集約を減らす方針で、遅延改善量は保証しません。受信側（`AMSDURx`）は、このドライバーで OFF が集約待ち削減になる機構を確認できないため、現値を維持します。
- PCIe 接続の Realtek では、対応する Flow Control・Advanced EEE を OFF にします。UDP URO は標準項目を公開し、ON/OFF に対応する物理 NIC だけ OFF にします。
- Realtek 製有線 NIC では、確認済みドライバーや対応する電源管理機能でデバイスの電源オフ設定を無効化します。この設定を扱わない場合は、対応条件を満たす Selective Suspend（選択的な省電力）を無効化します。両方を同時には変更せず、設定できない場合や保存済みの復元情報と競合する場合は結果に表示します。
- 対応可否は確認済みの媒体・メーカー・設定項目に限ります。他社の独自設定や非対応項目へ同じ値を推測して適用することはありません。
- 仮想 NIC・対象外のオフロード・リンク速度・バッファー・周波数帯・チャンネル幅・ローミングは変更しません。PC 全体の TCP 設定と NIC 側の RSS・オフロード設定は別に確認します。
- NIC の省電力無効化は消費電力や発熱、バッテリー駆動時間に影響します。電波やアクセスポイントの問題を直す機能ではありません。
- DNS や TCP、その他の設定を元に戻すボタンではありません。
